# NTS Group website (prototype)

Static site: plain HTML, CSS and JavaScript. No build step.

## Deploy on Vercel
1. Import this repository in Vercel.
2. Framework Preset: **Other**. Leave Build Command and Output Directory empty (root directory `./`).
3. Deploy.

The sitemap.xml uses the placeholder domain www.example-nts.co.uk. Replace it with the live domain before launch.
